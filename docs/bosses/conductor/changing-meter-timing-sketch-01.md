# Changing Meter timing sketch 01

Date: 2026-09-14

Review URL: `meter-lab.html`

## Purpose

This isolated twelve-second study tests whether the regrouping from `3+2` to
`2+3` is audible and readable before any new whole-character animation is made.
It occupies the provisional 16–28 second slot in The Conductor encounter.

## Timing

- Provisional tempo: 120 BPM.
- One pulse every 500 ms.
- Two five-pulse bars grouped `3+2`, then two grouped `2+3`.
- Strong pulses are 1 and 4 in `3+2`; they become 1 and 3 in `2+3`.
- The first second prepares the phrase; the final second withdraws toward the next
  encounter passage.

## Boundaries

- Web Audio clicks are a disposable timing reference, not composed music or final
  sound design.
- Red arcs are placeholder visualization using the already accepted low-hazard
  language.
- Rests retain an audible pulse but release no attack.
- There is no Conductor artwork, gesture animation, collision, player, HP logic,
  organ-pipe barrier, or absorbable stage event in this study.
- HP variants must preserve the authored musical release grid and will be designed
  only after the baseline grouping is accepted.
